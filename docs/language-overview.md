# SINS Language Overview
## Language Name and Description
SINS is a small programming language designed by our group for this project. The name SINS is formed from the first initials of the four group members. Our goal is to create a language with simple and readable syntax for variables, numeric calculations, decisions, loops, printing, and functions. The language is intended to be easy for beginners to understand and practical for our group to implement.

## Keywords

The proposed keywords for SINS are:

- `let` - declares a variable
- `print` - displays a value
- `if` - begins a conditional statement
- `else` - provides an alternative branch
- `while` - begins a loop
- `func` - defines a function
- `return` - returns a value from a function

## Operators

### Assignment Operator

- `=` - assigns a value to a variable

### Arithmetic Operators

- `+` - addition
- `-` - subtraction
- `*` - multiplication
- `/` - division

### Comparison Operators

- `==` - equal to
- `!=` - not equal to
- `<` - less than
- `<=` - less than or equal to
- `>` - greater than
- `>=` - greater than or equal to

## Delimiters

- `(` and `)` - group expressions, conditions, parameters, and arguments
- `{` and `}` - enclose blocks of statements
- `;` - ends a statement
- `,` - separates parameters and arguments
